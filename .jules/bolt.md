## 2025-05-18 - Avoid Element-by-Element Pandas .iloc Lookups and Unvectorized Window Max/Min in Core Scanner Loops
**Learning:** In pandas/numpy market structure code evaluated over hundreds of bars across a large stock universe (Nifty 500), calling `.iloc[i]` in Python loops or `np.nanmax(slice)` per iteration introduces substantial Python object overhead and pandas indexer dispatch penalty. Converting Series to NumPy arrays (`.to_numpy()`) and using `np.lib.stride_tricks.sliding_window_view` reduces single-stock analysis latency from ~80ms to ~37ms (>50% speedup) with zero change in output.
**Action:** Always extract NumPy arrays prior to bar-by-bar iterations and use `sliding_window_view` or vectorized NumPy array indexing for windowed rolling metrics in core calculation loops.
